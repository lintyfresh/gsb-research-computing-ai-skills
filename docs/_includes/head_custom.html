{% comment %} Theme resolution runs FIRST and inline (not deferred), before the browser paints, so a reader who chose dark never sees a flash of the light theme. This works because Just-the-Docs includes head_custom.html at the very end of its own _includes/head.html, after the theme stylesheet link — so by the time this runs, the link element exists and can still be rewritten pre-paint. Keep it inline. Moving it to an external or deferred script reintroduces the flash. {% endcomment %}
